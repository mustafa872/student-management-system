# 🛠️ سجل الأخطاء — ما الذي حدث؟ لماذا؟ كيف صلحناه؟

**آخر تحديث:** 2026-10-31.  
هذا سجل للأخطاء **التي ظهرت فعلاً**، لا قائمة افتراضات. لا تحفظ كلمات مرور أو محتوى `.env` الحساس.

## ERR-001 — Apache Not Found بمشروع PHP القديم

- **المشهد:** فتح صفحة المشروع القديم أعطى `Not Found`.
- **السبب:** URL لا يطابق مسار المجلد داخل `htdocs`.
- **الحل التاريخي:** استخدام المسار المطابق: `/test/chatgpttest/project/config.php`.
- **الدرس:** افحص URL وDocumentRoot قبل تغيير كود Database.
- **الحالة:** ✅ محلول.

## ERR-002 — ترتيب شرط POST وelse في PHP

- **المشهد:** خطأ ترتيب فحص `REQUEST_METHOD` و`else` في معالجة Form.
- **الإصلاح:** `if (POST) → receive → validate → insert`.
- **الدرس:** اكتب الخطوات منطقياً قبل وضع `if`/`else`.
- **الحالة:** ✅ فُهم.

## ERR-003 — Laravel 13 غير متوافق مع PHP السابق

- **المشهد:** `composer create-project` تعرقل بسبب إصدار PHP.
- **السبب:** متطلبات Laravel 13 أعلى من إصدار PHP القديم المستخدم.
- **الإجراء:** العمل على Laravel 12 ثم تحسين إعداد PHP CLI.
- **فحص آمن:** `php -v`, `composer --version`, `php artisan about`.
- **الدرس:** PHP الخاص بالطرفية ليس بالضرورة PHP الخاص بـ Apache.
- **الحالة:** ✅ تجاوزناه.

## ERR-004 — Laravel Extra Intellisense وPHP 8.0.30

- **المشهد:** Extension يفشل في قراءة Routes/Models/Views.
- **السبب المسجل:** الطرفية تستخدم PHP 8.0.30 وPackages تحتاج PHP >= 8.2.
- **الفحص:** `where.exe php`, `php -v`, ومراجعة PATH في الطرفية المعنية.
- **الحالة:** 📘 السبب معروف؛ ضبط PATH الدائم يحتاج فحص بيئتك الحالية.

## ERR-005 — إعداد قاعدة البيانات في `.env`

- **المشهد:** التباس بين قيم Driver/اسم القاعدة، واستخدمنا SQLite في فترة وMySQL في أخرى.
- **التصحيح:** تحديد قاعدة التشغيل الفعلية بوضوح قبل أي Migration.
- **معلومة زمنية:** آخر سجل بتاريخ 30-10-2026 أظهر `Database=mysql`.
- **فحص آمن:** `php artisan about`, `php artisan migrate:status`.
- **الحالة:** ✅ فُهم؛ نراجع الوضع الحالي عند أي تغيير.

## ERR-006 — `mb_split()` / mbstring في Tinker

- **المشهد:** فشل متعلق بـ `Illuminate\Support\mb_split()`، وظهرت تحذيرات Extensions.
- **السبب المرجح:** `mbstring` غير محمّل أو `extension_dir` يشير إلى إصدار PHP آخر.
- **الفحص:** `php --ini`, `php -m`, `php -i` ثم مراجعة `extension_dir`.
- **الدرس:** لا تنقل DLL بين إصدارات PHP دون تحقق.
- **الحالة:** 🟡 لا يوجد إثبات متاح لإصلاح نهائي شامل.

## ERR-007 — `$this->authorize()` غير معروفة

- **المشهد:** استدعاء `authorize()` في StudentController لم يعمل.
- **السبب:** Base Controller لم يحتوِ `AuthorizesRequests` Trait.
- **التعديل الذي استخدمناه (هيكل مختصر):**

```php
use Illuminate\Foundation\Auth\Access\AuthorizesRequests;

abstract class Controller
{
    use AuthorizesRequests;
}
```

- **الدرس:** Trait يضيف Methods للـ Class؛ لا تحذف Traits/كود Controller الآخر عند التطبيق.
- **الحالة:** ✅ محلول.

## ERR-008 — PHP Parse Error قرب `edit(Student $student)`

- **المشهد:** خطأ Syntax قرب `$this`.
- **السبب الذي اكتشفناه:** محرف غير متوقع/غير ASCII في سطر فتح الدالة.
- **التعديل:** حذف المحرف وإعادة كتابة السطر يدوياً.
- **التحقق:** `php -l` أعطى Syntax OK.
- **الحالة:** ✅ محلول.

## ERR-009 — HTTP 403 عند حذف طالب ليس للمالك

- **المشهد:** `This action is unauthorized`.
- **السبب:** `StudentPolicy::delete()` ترجع `false` للمستخدم غير المالك، وController يفرض القرار.
- **النتيجة:** **هذا سلوك حماية صحيح**، مو عطل مطلوب تعطيله.
- **الفحص:** `Gate::forUser($user)->allows('delete', $student)` دون الحذف الفعلي.
- **الحالة:** ✅ صحيح.

## ERR-010 — Blade Layout و`$slot`

- **المشهد:** خطأ في Layout عند عرض صفحة تفاصيل الطالب.
- **السبب:** تداخل Blade Component Layout مع نمط `@extends/@section`.
- **الإجراء:** توحيد طريقة استخدام الـ Layout والـ View.
- **الدرس:** `$slot` متعلق بنمط Components، و`@yield/@section` بنمط الوراثة.
- **الحالة:** ✅ عولج أثناء تصميم الصفحة.

## ERR-011 — مقطع ملف يحمل اسم User.php لكنه ليس User Model

- **المشهد:** ملف نصي أُرسل للتوثيق احتوى تحت عنوان `User.php` كوداً من `Psy\Readline`.
- **السبب:** النص المجمّع ليس دليلاً موثوقاً على بنية `App\Models\User`.
- **القرار:** عدم بناء أي استنتاج عن User Schema من هذا المقطع؛ نحتاج الملف الصحيح.
- **الحالة:** ✅ تم اكتشافه عند إعداد المرجع.

- لا تضف `UNIQUE` إلى جداول تحتوي بيانات قد تكون مكررة قبل فحصها وBackup.
