## التركيب على Windows وVS Code

1. فك ملف ZIP.
2. ضع محتويات `Laravel-Learning-Reference-v2` هنا:
   `C:\xampp\htdocs\student-management-system\docs\learning\`
3. افتح المشروع في VS Code وافتح `MASTER-REFERENCE.md` ثم `Ctrl + Shift + V` للمعاينة.
4. من الأفضل حفظ `docs/learning` مع Git، مع استثناء أسرار العمل وملفات `.env` غير الآمنة.

**إذا عندك نسخة سابقة:** احتفظ بنسخة احتياطية قبل الاستبدال، خصوصاً إذا أضفت ملاحظاتك الخاصة. `OUR-LEARNING-HISTORY.md` أرشيف معرفي، و`progress.md` سجل إنجاز، فلا تخلطهما.

## كيف ندرس من هذا المرجع؟

1. نبدأ **بالمفهوم** ثم **ليش نحتاجه**.
2. نقرأ مثال الكود **سطر بسطر** قبل تشغيله.
3. المستخدم يحاول كتابة الحل، ويجي التصحيح **خطأ واحد بوقت واحد**.
4. نجري تجربة صغيرة في بيئة تطوير/اختبار، ثم اختبار 12 سؤالاً للدرس الكبير.
5. نحدث `progress.md` و`session-log.md` وبنك الأسئلة، ونكتب الخطأ الجديد في `error-log.md`.
6. لا ننتقل إلى درس جديد إذا باقي خطأ أساسي غير مفهوم.

**ما الذي لا يعنيه وجود هذا الكتاب؟** عرض فصل مثل API أو Deployment لا يعني أننا درسناه. حالة الإتقان الحقيقية في `CURRICULUM.md` و`progress.md`. كذلك هذه موسوعة تعليمية مبنية على Laravel 12 وليست نسخة من كل صفحة في وثائق API الرسمية؛ التفاصيل المتغيرة تُراجع هنا: https://laravel.com/docs/12.x

## التحديثات القادمة

بعد كل درس: ارفع **آخر نسخة ZIP** أو الملفات التي تغيرت في المحادثة الجديدة، وسأدمج الفصل/الأمثلة والاختبار والنتيجة وأرجع إصداراً أحدث. لا يوجد تعديل مباشر تلقائي لملفات جهازك ولا متابعة بالخلفية. لا تضع كلمات مرور، Tokens، بيانات دخول، أو معلومات حساسة في أي ملف مرجعي.

## نقطة الدراسة الحالية

`Laravel Authorization` → `StudentPolicy::before()` → `true/false/null` → ترتيب `blocked/admin` والتحقق من وجود Method للـ Ability → اختبار المالك وغير المالك. نُغلق الدرس بعد الاختبار العملي وليس بالقراءة.
