# Student Management System — Learning Progress

## 1. معلومات التعلّم

- **المسار:** PHP → SQL/PDO → Laravel
- **المشروع العملي:** Student Management System
- **مستوى البداية المسجّل:** Upper Beginner / Early Intermediate
- **أسلوب الدراسة:** شرح المفهوم، سبب استخدامه، مثال، تحليل الكود، تطبيق عملي، اختبار، ثم مراجعة تراكمية.
- **القاعدة الأساسية:** لا يُعتبر المفهوم متقناً لمجرد حفظ التعريف أو مشاهدة الحل؛ يجب شرحه وتطبيقه بصورة مستقلة.

## 2. نقطة التوقف الحالية

- **الموضوع:** Laravel Policies و Authorization
- **آخر نقطة نراجعها:** التحقق من صلاحية المستخدم لتعديل أو حذف سجل طالب.
- **المفاهيم المرتبطة:**
    - Authentication مقابل Authorization
    - Policy
    - `authorize()`
    - `can()`
    - `Auth::id()`
    - ملكية السجل (Record Ownership)
    - `edit()` مقابل `update()`
    - حماية `user_id`
    - `$fillable` و Mass Assignment
- **ملفات المشروع ذات الصلة:** `StudentController.php`، `StudentPolicy.php`، `Student.php`، `AuthServiceProvider.php` أو آلية تسجيل Policies المستخدمة في إصدار Laravel الحالي.
- **ملاحظة:** يجب التحقق من الكود الفعلي قبل إجراء تغييرات؛ أسماء الملفات وآلية التسجيل قد تختلف حسب إعداد المشروع.

## 3. حالة الإتقان

تُحدّث هذه القائمة بعد الاختبار العملي فقط.

| المفهوم                            | الحالة       | الدليل المطلوب                    |
| ---------------------------------- | ------------ | --------------------------------- |
| Authentication مقابل Authorization | قيد المراجعة | شرح الفرق بمثال                   |
| وظيفة Policy                       | قيد المراجعة | شرح دورها في حماية السجلات        |
| `authorize()`                      | قيد المراجعة | تطبيق صحيح في Controller          |
| `can()`                            | قيد المراجعة | شرح الفرق عن `authorize()`        |
| `Auth::id()`                       | قيد المراجعة | تطبيق يربط السجل بالمستخدم الحالي |
| ملكية سجل الطالب                   | قيد المراجعة | اختبار مستخدمين مختلفين           |
| `edit()` مقابل `update()`          | قيد المراجعة | توضيح دورة الطلب HTTP             |
| حماية `user_id`                    | قيد المراجعة | منع تغيير المالك عبر Request      |
| `$fillable`                        | قيد المراجعة | شرح Mass Assignment بأمان         |

**معاني الحالات:**

- لم يبدأ: لم ندرسه بعد.
- قيد المراجعة: نحتاج شرحاً أو اختباراً.
- يحتاج تعزيزاً: الفكرة مفهومة لكن التطبيق غير ثابت.
- متقن: شرح مستقل وتطبيق ناجح واختبار للحالات المتوقعة.

## 4. قواعد الانتقال بين الدروس

لا ننتقل إلى المفهوم التالي حتى يستطيع المتعلّم:

1. شرح المفهوم بكلماته.
2. تفسير سبب استخدامه والمشكلة التي يحلّها.
3. قراءة الكود وفهم الأسطر المهمة.
4. كتابة تطبيق صغير دون نسخ الحل كاملاً.
5. اختبار الحالة الصحيحة والحالة الممنوعة.
6. الإجابة عن سؤال مراجعة مرتبط بدرس سابق.

النتيجة الرقمية للاختبار مؤشر مساعد وليست الدليل الوحيد على الإتقان.
